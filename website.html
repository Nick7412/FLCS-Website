F.L.C.S.

Fabric Laser Cutter System

University of Central Florida Senior Design Project — Group 2. An automated laser-based system designed to accurately cut fabric using computer vision, motion control, and an integrated touchscreen interface.

Project Overview

F.L.C.S. combines hardware, software, computer vision, and motion control into a single fabric-cutting system.

Computer Vision

A camera-based system captures fabric markings and processes them into cutting paths.

Laser Cutting

Generated cutting paths are converted into G-code for controlled laser movement across the fabric.

Touchscreen HMI

An integrated touchscreen interface allows users to configure, monitor, and control the cutting process.
